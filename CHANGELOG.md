# Changelog

All notable changes to Collar for QGIS are recorded here. Version numbers match
`collar_qgis/metadata.txt`.

## 0.4.1

- Rename standalone polygons to **Work areas** (`work_area`).

## 0.4.0

- Two-way managed **Tracks** sync for authorised create/edit users.
- Viewers continue to see published tracks read only.
- Discovery no longer offers legacy Track / Access tracks spatial categories.

## 0.3.2

- Closer-zoom Esri imagery fallback that matches Collar's missing-tile behaviour.
- In-place upgrade for Collar-managed Esri layers.

## 0.3.1

- Propose hole move review overlay with temporary canvas graphics.
- Hole label outlines aligned with Collar's outline rule.

## 0.3.0

- Dock account display, sign-out and Settings window.
- Separate operational layers (holes, pads, sumps, disturbance).
- Optional Esri imagery basemap when loading project layers.
- Collar styling action for selected layers.

## 0.2.0

- Organised layer discovery and organisation map styling.

## 0.1.0

- Initial experimental preview: browser sign-in, project layers, reviewed sync and publishing.
