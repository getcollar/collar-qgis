# Collar for QGIS

Native QGIS plugin for Collar drilling and exploration projects.

## Install

1. Use QGIS 3.40 or later (Windows, macOS or Linux).
2. Install from the [QGIS Plugin Repository](https://plugins.qgis.org/) when listed, or via **Plugins → Manage and Install Plugins → Install from ZIP** using a trusted release build.
3. Enable **Collar for QGIS**, then open **Plugins → Collar → Collar for QGIS**.

No pip packages are required. An active Collar organisation account is required.

## Quick start

1. Choose **Connect to Collar** and sign in in your browser.
2. Select an organisation and project, then **Load layers**.
3. Edit supported layers with normal QGIS tools, save the project, then **Sync changes to Collar**.
4. Use **Publish to Collar** for prepared vectors or GeoTIFF imagery.

Full usage guides:

- https://getcollar.io/support/maps/collar-for-qgis
- https://getcollar.io/support/maps/qgis-sync-and-publish
- https://getcollar.io/integrations/qgis
